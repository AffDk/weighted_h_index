\section{Experiments}

\subsection{Dataset}

We sampled $N$ researchers from OpenAlex across computer science and artificial intelligence. For each researcher we fetched:
\begin{itemize}
    \item All works in their oeuvre (with abstracts),
    \item All works citing those works (with abstracts),
    \item Citation edges: citing paper $\to$ cited paper.
\end{itemize}

Each edge was scored by the LLM relevance scorer to obtain $w \in [0,1]$. Responses were cached by abstract-pair hash to avoid redundant API calls.

\subsection{Metrics}

We evaluated three h-index variants per researcher:
\begin{enumerate}
    \item \textbf{Conventional h-index:} each citation weight $=1$.
    \item \textbf{Weighted h-index:} each citation weight $=w(p_i\to p_j)$ from LLM relevance scoring.
    \item \textbf{Hip-index (Zhu et al.):} reference implementation using $c^2$ weighting where full-text mention counts are available.
\end{itemize}

We report:
\begin{enumerate}
    \item \textbf{Spearman correlation} between author rankings by each pair of methods.
    \item \textbf{Precision@N} at identifying top researchers, using a ground-truth set of influential researchers (e.g., ACL Fellows, award winners, or top-$K$ by conventional h-index).
    \item \textbf{Average Precision (AveP)} as in Zhu et al. (2015).
    \item \textbf{Threshold ablation}: counting only edges with $w \ge \tau$ for $\tau \in \{0.3, 0.5, 0.7\}$.
\end{enumerate}

\subsection{Hypothesis}

The weighted h-index should reorder researchers relative to the conventional h-index: researchers whose citations are genuinely influential (high relevance weights) should rank higher under the weighted variant, while researchers inflated by courtesy/colleague citations (low relevance) should rank lower. We expect the largest divergence in the middle of the ranking distribution.
